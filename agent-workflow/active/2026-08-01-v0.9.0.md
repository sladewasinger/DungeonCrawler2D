  all edits and diff checks must remain path-explicit.
- Release notes can overstate behavior when inferred from commit subjects.
  Claims must be checked against the committed implementation/tests in the
  selected range and written as player outcomes.
- `package-lock.json` can rewrite unrelated dependency metadata. Reject any
  lockfile diff beyond the root and four workspace version records.

  notes are at `0.8.0`. This slice does not repair release history; the parent
  must resolve publication sequencing separately before any v0.9.0 tag or
  deployment.

  The dirty feature branch and preserved ICM conversion prevent treating this
  planning cycle as a clean release checkout.
