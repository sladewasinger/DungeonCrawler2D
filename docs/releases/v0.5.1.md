## Added

- Added a subtle, wall-aware pool of light around the player so dark rooms remain readable without weakening torchlight.
- Added visible four-second revive progress for any nearby player helping a downed crawler.
- Added a clickable “Respawn Now” action to the death screen alongside hold-E.

## Changed

- Ordinary deaths now respawn after 10 seconds for solo players or 15 seconds in a party; downed crawlers bleed out after 30 seconds, and any nearby living player can attempt a revive.
- Touch controls now appear and disappear as the active input method changes between touch, keyboard, and mouse.
- Death-loot chests now expire after five minutes.

## Removed

- Removed the flat debug-line stair artwork from live stair surfaces.

## Fixed

- Fixed stairs in every direction so their five stepped bands, elevation, highlights, and camera rotation read consistently.
- Fixed safe-room attendant speech and nameplates being hidden by terrain, and renamed Nib to “Nib, Safe Room Attendant.”
- Fixed missing solid walls around south exit halls in personal, party, and safe rooms.
- Fixed the title controls description failing to relayout after viewport changes.
- Fixed death-loot prompts selecting a different chest than the interaction action, first presses being lost, and held keys sending duplicate opens.
- Fixed personal rooms sharing state between duplicate sessions while keeping party and safe rooms shared.
- Fixed enemies continuing to target fully dead players.
- Fixed blood, corpses, fragments, and death-loot chests rendering beneath the floor while preserving real wall occlusion.
- Fixed hold-E early respawn input and progress across the supported game renderers.
- Made the “YOU DIED” headline larger, vivid red, outlined, and responsive on narrow screens.

<!-- developer-only -->
- Stair rendering now uses a direction-independent five-band surface contract instead of production debug frames.
- Player ground lighting is pooled, capped, throttled, ground-projected, and can be disabled independently as a performance fallback.
- Loot opening now sends the prompted chest id through an explicit authoritative open operation.
- Revives use explicit start/release intents and a server-owned attempt lifecycle with authoritative cancellation.
