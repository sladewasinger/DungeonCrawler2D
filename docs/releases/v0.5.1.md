## Added

- Added a smooth, wall-aware four-tile pool of uniform floor light around the player so dark rooms remain readable without orb-like gradients.
- Added visible four-second revive progress for any nearby player helping a downed crawler.
- Added a red “Give Up” action and a two-second hold-E alternative while downed.
- Added a two-click terrain-editor stair tool that authors the stair tile, direction, and one-level landing transition.

## Changed

- Every player death now enters a 15-second downed window followed by a mandatory five-second dead screen; party membership does not change either timer.
- Browser tabs now keep separate multiplayer identities and resume tokens while retaining shared name and character defaults.
- Touch controls now appear and disappear as the active input method changes between touch, keyboard, and mouse.
- Death-loot chests now expire after five minutes.

## Removed

- Removed the flat debug-line stair artwork from live stair surfaces.
- Removed instant-respawn buttons and keyboard shortcuts from the fully dead screen.

## Fixed

- Fixed north/south stairs so their widening treads read as depth and no false wall is drawn beneath them, while preserving the established east/west artwork.
- Fixed safe-room attendant speech and nameplates being hidden by terrain, and renamed Nib to “Nib, Safe Room Attendant.”
- Fixed missing solid walls around south exit halls in personal, party, and safe rooms.
- Fixed the title controls description failing to relayout after viewport changes.
- Fixed death-loot prompts selecting a different chest than the interaction action, first presses being lost, and held keys sending duplicate opens.
- Fixed personal rooms sharing state between duplicate sessions while keeping party and safe rooms shared.
- Fixed enemies freezing around downed players; they now drop the target and resume normal movement.
- Fixed downed players rapidly shaking between authoritative and speculative render positions.
- Fixed Basic auto healing appearing or activating while a player is downed or dead.
- Fixed blood, corpses, fragments, and death-loot chests rendering beneath the floor while preserving real wall occlusion.
- Fixed the live 2D frame order resetting hold-E Give Up progress before it could complete.
- Made the “YOU DIED” headline larger, vivid red, outlined, and responsive on narrow screens.

<!-- developer-only -->
- North/south stair surfaces use perspective tread spacing; east/west surfaces retain their original equal-band profile.
- Player ground lighting uses capped solid tile overlays with five brightness rings and a bounded cross-fade pool; constrained devices retain the radial fallback.
- The production input adapter now delegates loot-chest and revive operations through the real connection contract.
- Revives use explicit start/release intents and a server-owned attempt lifecycle with authoritative cancellation.
