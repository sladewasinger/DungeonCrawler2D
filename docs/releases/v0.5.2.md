## Added

- Added collectible pet NPCs from the new dinosaur and enchanted-forest art
  packs. The first nearby crawler to press E claims a pet; claimed pets follow,
  drift while idle, recover with bounded pathfinding, and teleport back after a
  long separation.
- Added shared bounded grid pathfinding for future NPCs, including terrain
  height, jump edges, stair direction, void safety, and side-rim-aware stair
  traversal.
- Added a god-mode stamina grant: sprinting and blocking no longer consume
  stamina while god mode is active.
- Added percentage-based HUD panel sizing so layouts scale with the viewport.

## Changed

- Revive progress is now visible to every nearby crawler, not only party
  members or the player participating in the revive.
- Weapons, attack cones, and melee wedges now use projected depth so they stay
  above the appropriate terrain faces.
- Pet labels use the pet name with a smaller second line identifying its owner.
- Pet follow navigation now recognizes half-height and taller ledges as jump
  transitions and approaches stairs from their valid low/high ends.

## Removed

- Removed the missing stair traversal helper import that prevented the client
  build from resolving shared navigation code.

## Fixed

- Fixed crawler-name input retaining in-game command bindings after returning
  to the title screen.
- Fixed mobile inventory opening the keyboard by auto-focusing the filter.
- Fixed pets getting stuck repeatedly pushing into the side of a staircase
  beside a void ledge.
- Fixed the client build failing when resolving the shared stair traversal
  helper.

- Kept pet behavior split into expandable feature slices for future combat and
