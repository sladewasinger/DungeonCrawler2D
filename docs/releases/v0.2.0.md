## Added

- Party invitations now have a visible management panel where incoming invitations can be accepted or declined and outgoing invitations can be cancelled.
- Bandages can now be applied to a nearby player by equipping one and pressing F.
- Exhausted players visibly pant while waiting for stamina to recover.
- The title screen now uses the shared dungeon-door presentation in both game modes, with rising ember effects.
<!-- developer-only -->
- Party invitation state is replicated with explicit incoming/outgoing add/remove events and restored across reconnect snapshots.
- Safe-room snapshots now describe per-player personal or party doors independently of shared world tiles.
- The 2D renderer now owns a pooled guard-cone visual and pooled out-of-breath effect.
<!-- /developer-only -->

## Changed

- Blocking slows movement to half speed, uses a compact defensive weapon pose, and protects only against attacks arriving inside the visible guard cone.
- Players face toward their aimed weapon while horizontal facing remains stable during vertical movement.
- Blood impacts and enemy deaths now produce larger, brighter splashes and visible gore-and-bone remains that fade after thirty seconds.
- Chat is slimmer and more transparent, with its channel tabs below the input.
- The compass is centered at the top without a panel background, and the HUD now displays the game version above the build number.
- Safe rooms now contain only the distinct dungeon exit and each occupant's personal or party door.
- Player lighting no longer displays a white orb in either renderer.
<!-- developer-only -->
- The HUD shell moved to dedicated HTML and CSS templates shared by the 2D and 3D routes.
- Directional block resolution is shared by melee, enemy strikes, PvP, and direct hostile projectiles.
- Release-note generation hides developer-only blocks from public HTML while retaining them in source Markdown.
- Enemy population maintenance recycles dormant offscreen hostiles and apportions the global cap across occupied dungeon areas.
<!-- /developer-only -->

## Removed

- Removed the legacy canvas-only 2D title screen.
- Removed the communal chest and crafting table from shared safe rooms.
- Removed visible white player-light orbs from 2D and 3D.
<!-- developer-only -->
- Removed duplicated TypeScript-built HUD structure superseded by the shared HTML template.
<!-- /developer-only -->

## Fixed

- Blood and gore now render at an enemy's final position even when the same server snapshot removes that enemy.
- Enemies no longer disappear permanently after exploration fills the server's population cap, and cleared active areas begin repopulating within thirty seconds on every dungeon floor.
- Blocking weapons now keep the correct orientation on both sides of the player.
- Basic automatic healing no longer shows floating health numbers, and its buff indicator disappears immediately after damage.
- Fast mouse turns in 3D no longer produce sudden random view rotations.
- Party invitations now provide clear feedback to both the sender and recipient.
<!-- developer-only -->
- Combat visual events capture position, content identity, and entity kind before snapshot pruning so deferred VFX rendering cannot lose lethal-hit targets.
- The floor-five Warden is excluded from ordinary inactive-enemy recycling.
- Snapshot self-state, projectile source resolution, social chat, invite events, and directional blocking were split into focused modules to retain static complexity and file-size gates.
<!-- /developer-only -->
