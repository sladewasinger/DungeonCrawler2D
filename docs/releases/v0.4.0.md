## Added

- Every monster family from Dungeon Tileset II now appears in the dungeon, including goblins, zombies, demons, beasts, fallen angels, and a complete orc roster.
- Similar enemies now travel in cohesive packs, with biome-native populations and occasional off-theme wanderers.
- Large rooms can contain an Orc Warlord mini boss guarded by three orc minions. Warlords have substantially more health, damage, loot, and XP than ordinary enemies.
- Player deaths now create a labeled loot chest one or two tiles from the body, preserving the full inventory for individual or take-all looting.
- Killers receive exclusive chest access for sixty seconds. Afterward anyone may loot it, but only one player can view a chest at a time.
- Advanced settings now organize graphics, accessibility, carnage, and tutorial controls into tabs.
- Death recovery now counts down for thirty seconds and supports a visible three-second hold-E early respawn.
- The world status panel now shows the current biome and a mouse-aimed heading in 2D.
<!-- developer-only -->
- Death-loot chests are authoritative entities with private contents, server-owned viewer claims, range/death/disconnect cleanup, thirty-minute expiry, and protocol-versioned take/close intents.
- Enemy population uses deterministic district rosters, bounded pack placement, generated BSP room bounds, and persistent defeated-room tracking for mini bosses.
- Mini-boss encounters share room leashes so the warlord and guards cannot wander into halls or neighboring rooms.
- HUD window layouts persist normalized viewport-relative positions and sizes, then clamp back into view after browser resizing.
<!-- /developer-only -->

## Removed

- Removed the pre-v0.4 sparse enemy roster and placeholder population fallback.

## Changed

- Blood droplet intensity is configurable and the default death burst is less excessive.
- Gore is disabled by default while blood remains enabled, with both settings persisted across page loads.
- Stairs now have directional depth: side views descend diagonally and north-facing steps use perspective spacing.
- Personal rooms now match the other room types with a recessed exit hallway, an exit label, and a vertically centered room label.
- Unarmed crawlers use a neutral circular fist marker instead of a dagger placeholder.
- Skeleton impacts emit randomized bone chips instead of blood.
- The settings-menu quit action is now named “Quit to title.”
<!-- developer-only -->
- Wall/void generation repeatedly caps isolated height peaks to one z-level above their highest adjacent tile.
- The production title excludes the local sandbox entry, while local builds retain the developer shortcut.
- Chest rendering, interaction priority, stash presentation, labels, lock countdowns, and proximity rules are shared across the 2D and 3D clients.
<!-- /developer-only -->

## Fixed

- Dead local and remote players no longer leave a second standing animated sprite over their body.
- The basic auto-healing buff disappears as soon as health is full.
- Out-of-stamina panting effects now track changes in player elevation.
- Chat can only capture combat input after Enter, and clicking outside it immediately returns control to the game.
- HTML controls no longer retain tab focus, text selection, or a settings-button focus state that turns Space into an accidental menu shortcut.
- HUD edit mode no longer closes the game menu when enabled.
- HUD panels remain reachable when the browser window is resized.
- Loot ownership cannot be bypassed by stale indices, simultaneous viewers, walking away, dying, disconnecting, or modified clients.
<!-- developer-only -->
- Death-loot item transfers are atomic, address individual stacks by item id, and remove empty or expired chests from replication and spatial queries.
- Enemy placement continues to exclude walls, sanctuaries, and lethal chasms while the expanded population stays under the global cap.
<!-- /developer-only -->
