---

## Added

- Added device-aware graphics resource limits for smoother play across phones, tablets, and desktop computers.

## Changed

- Dungeon terrain now bakes at its native pixel-art resolution and scales sharply at display time instead of storing nine enlarged pixels for every source pixel.
- Terrain texture reuse now obeys strict active and spare memory budgets selected for the current device.
- Door labels now render at display resolution so they remain readable while the terrain uses smaller textures.

## Removed

- Removed oversized display-resolution terrain textures and excessive spare texture retention.

## Fixed

- Fixed escalating terrain memory use that could cause Chrome to display an "Aw, Snap!" crash page during mobile play.
- Fixed camera rotation and chunk streaming getting stuck when the terrain page budget was temporarily exhausted.
- Fixed debug wall borders and structure labels becoming distorted after the native-resolution conversion.
<!-- developer-only -->
- Terrain texture dimensions now have an independent 1024-pixel hard ceiling, and every terrain entrypoint explicitly configures its device profile.
- Budget-blocked chunk builds now release stale replacements safely, retry only after usable capacity is released, and fail fast in synchronous tools instead of spinning forever.
- Removed the Playwright E2E suite, CI browser install, and obsolete terrain diagnostics hooks while retaining Playwright-backed screenshot and icon utilities.
<!-- /developer-only -->
