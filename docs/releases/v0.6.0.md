## Added

- Added larger, connected dungeon districts with wider passages, varied
  elevation, stairs, pits, platforms, structural bedrock, biome color, and
  dedicated mini-boss spaces.
- Added a protected spawn room with a one-way exit and an enthusiastic dungeon
  announcer.
- Added enclosed mini-boss arenas with gated entry, parkour platforms, and
  encounters that remain dormant until a crawler enters.
- Added kid and mobile assisted aiming, unified revive feedback, configurable
  void terrain, and dedicated interior presentation for safe, personal, party,
  and spawn rooms.
- Added readable status presentation: partial poison tinting, attached burning
  effects, and a dedicated oil debuff with dripping visuals.

## Changed

- Rebuilt the 2D dungeon renderer for faster camera movement, bounded resource
  use, clearer wall depth, improved lighting, rounded edges, and more readable
  interior rooms.
- Reworked terrain generation around district-scale layouts while retaining
  streamable 32-by-32 runtime chunks.
- Enemies now use terrain-aware sight, remember a crawler's last known
  position, search the surrounding area, and navigate elevation more
  deliberately.
- Camera rotation now uses Z and X, while held G previews a throwing arc and
  releases the item toward the selected landing point.
- Carnage now defaults on. Telemetry defaults hidden, the effects and equipped
  weapon panels use content-only presentation, and Basic Auto Healing is now
  named Dungeon Auto Healing.

## Removed

- Removed the legacy reference terrain generators and the old doubled world
  scaling path.

## Fixed

- Fixed numerous wall, stair, pit, void-edge, room-door, prop-layer, lighting,
  collision, pet-interaction, revive, and camera-zoom issues.
- Fixed entities, projectiles, items, and torches outside an interior room
  appearing inside that room.
- Fixed several terrain layouts that could trap crawlers or allow shortcuts
  across intended dungeon barriers.
- Fixed enemies oscillating or jumping in place after losing sight of a player,
  and fixed pets hovering when their owner stopped moving during a jump.
- Fixed duplicate party revive indicators, inaccessible mobile actions,
  inconsistent kid-mode facing, and several safe-room and spawn-room
  presentation issues.

<!-- developer-only -->
- Replaced the legacy generation path with a deterministic district planner
  while preserving authoritative 32-by-32 chunk streaming.
- Split terrain, wall-mounted features, props, entity geometry, lighting, and
  room presentation into domain-focused rendering paths with bounded caches.
- Added shared terrain line-of-sight, enemy pursuit memory, structural-bedrock
  classification, room-scoped entity visibility, and encounter safeguards.
- Added authoritative mini-boss gate state, bounded local enemy search,
  semantic status-visual lifecycles, and predictive throw targeting.
- Centralized terrain, room, lighting, announcer, void, enemy, and encounter
  tuning.
