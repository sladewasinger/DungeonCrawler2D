## Added

- Server-authoritative multiplayer dungeon movement, combat, inventory, crafting, parties, chat, floors, and reconnect continuity.
- Shared HTML HUDs for the primary 2D renderer and opt-in first-person Three.js renderer.

## Changed

- Movement replication now adapts input and snapshot cadence while preserving deterministic prediction and reconciliation.
- The opening screen and shared HUD use larger, clearer, keyboard-accessible controls.

## Removed

- Obsolete presentation and networking paths superseded by the shared renderer and protocol foundations.

## Fixed

- Mobile session recovery, fullscreen re-entry, dropped-delta baseline recovery, and authoritative bandage healing.
