# v0.8.0 Release Checklist

This checklist is a release gate, not evidence that the feature work is already
complete. Check an item only after its implementation, focused regression
coverage, and manual behavior have all been verified.

## Companion behaviors

- [ ] Tard farts occasionally while waiting near his owner and on every
      rate-eligible start-from-rest transition, including his own idle wander;
      the replicated green puff ejects behind his facing, travels roughly three
      times farther, lasts twice as long, and remains readable without covering
      gameplay.
- [ ] Doux chases his tail while waiting; the presentation never changes his
      authoritative position, collision, or pathing.
- [ ] Pets that do not have a defined unique behavior retain ordinary following
      behavior and do not inherit another dino's presentation.

## Combat and diagnostics

- [ ] Sword, dagger, and hammer load validated profiles with distinct shape,
      range, damage, knockback, and cooldown values, including the intended
      20-percent player-weapon reach increase without changing enemy reach.
- [ ] Attack previews follow player position only during the attack pulse,
      preserve their captured aim/profile, and hammer attacks use a
      ground-radius impact rather than a cone; recovery uses a separate
      horizontal cooldown bar with a one-shot held-weapon ready flash, and the
      full hitbox stays above screen-south floor/cap tiles. The server
      resolves the same 0–150 ms window from the player's current position,
      hits each target at most once, and lets cones hit all non-party hostiles
      without broadening party fallback damage.
- [ ] Successful melee and projectile blocks produce one visible feedback
      event and the shorter guard collider affects authoritative collision.
- [ ] A correctly timed weapon attack returns hostile direct spits, preserves
      their damage/status payload and player credit, cannot hit players after
      return, and does not affect oil lobs or item throwables.
- [ ] The Orc Warlord retains one of the existing three arena attacker slots
      and recovers from wall-side or guard-separated positions inside the full
      placed arena footprint.
- [ ] Enemy and player hurtboxes are axis-aligned boxes that match their visible
      bodies with the intended enemy/player padding; every shipped enemy has
      authored dimensions, weapon/projectile contact intersects those exact
      boxes, and deterministic geometry tests cover large targets, corners,
      tangency, and false-positive rejection.
- [ ] Local/admin-only debug controls independently toggle hurtboxes, hitboxes,
      guard volumes, line of sight, behavior state, searches, and navigation;
      the visible weapon hitbox is authoritative and checkbox state
      remains stable while awaiting the server response.
- [ ] The ordinary local Sandbox remains an enemy-free traversal course. The
      separate Combat Sandbox is a flat 50x50 enclosed arena with content-derived
      rows of items, weapons, and pets plus safely separated elemental fixtures.
      It replaces the TEST_FIXTURES startup mode.
- [ ] The Combat Sandbox contains one stationary Training Dummy with 150 HP and
      one sword Training Dummy that attacks players once per second with the same
      visible, authoritative cone hitbox as a player sword. They are separated by
      at least ten tiles, accept normal damage and status effects, show blood and
      damage numbers, grant XP, drop no loot, and return at full health one second
      after defeat without entering random dungeon populations.

## Spectate and administration

- [x] Spectators use a separate read-only server session and the full game
      renderer: selecting a connected player opens a contextual live viewer
      with smooth tracking, free camera, center, next, previous, HUD, and exit
      controls plus explicit zoom buttons, while the inspector camera remains
      independent and offers zoom/reset controls. Spectate is an on/off switch;
      a disabled viewer releases its connection. Ordinary living players cannot
      inspect hidden world state.
- [x] The admin portal and in-game commands share one authorization-checked,
      validated, rate-limited command service with audit records.
- [x] The admin route boots with valid dataset keys and resolves its map-level
      and spawn selectors through their existing `data-admin-*` attributes.
- [x] Admin login does not trust IP, User-Agent, browser fingerprint, or a
      client-supplied identifier as an authentication factor.
- [x] Refreshing `/admin` restores only a peer-bound, opaque server session
      key from tab-scoped `sessionStorage`; `ADMIN_TOKEN` is never stored in a
      URL or `localStorage`, and an expired/restarted server returns to login.
- [x] Authenticated admin state pushes connected-player presence and position
      updates without a manual refresh action; game and portal target the same
      WebSocket process during each playtest.
- [ ] Apply and verify the Terraform-defined encrypted DynamoDB operational
      history, 365-day per-event TTL, point-in-time recovery, least-privilege
      writer, 14-day CloudWatch structured-error retention and alarm, and
      operator query access. The in-repo implementation is documented in
      `docs/ADMIN-OPERATIONS.md`; repository code alone is not deployment
      evidence.
- [x] Enemy, item, weapon, and pet spawning accepts only approved definitions and
      server-validates placement on the simplified height map.
- [ ] The admin spawn catalog automatically covers every content-defined enemy,
      item, weapon, and pet in its matching category, with authored useful stats
      (including weapon knockback), safe unknown-art fallbacks, synchronized
      ordered map controls, tile-center placement, selected-player pet ownership,
      and right-click removal limited to server-authorized enemy and weapon markers.

## Minimap and HUD

- [ ] The compass is a cached circular top-down height map with capped dynamic
      marker refresh; it does not generate world chunks to draw itself.
- [ ] Enemies are red, ordinary players gray, party members green, safe rooms
      blue, mini-boss arenas red, stairs gold, and off-map waypoints retain edge
      indicators.
- [ ] The minimap remains square while resizing, and old HUD layouts clamp to
      valid dimensions without hiding health, stamina, or XP.

## Traversal safety

- [ ] The “I’m stuck” rescue selects only the nearest valid local 3×3 platform
      two to six tiles away; it may bypass the trapping void but never lands in
      a chasm, sanctuary, safe room, arena, occupied footprint, or distant
      fallback location. It preserves its cooldown and cancels active melee.
- [ ] Spawn and safe-room planes reject enemy population and admin enemy
      placement, render a non-walkable visual apron beyond their playable
      bounds, and never reveal or collide with the ordinary dungeon plane.
