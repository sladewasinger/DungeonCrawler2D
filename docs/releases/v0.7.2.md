title: Reliable Mini-Boss Arenas
---

## Added

- Added observer-aware mini-boss population so complete encounters are ready
  before a crawler reaches an arena gate.

## Changed

- Mini-boss encounters now unload when no connected crawler can observe their
  arena and return unchanged when an undefeated arena is approached again.

## Removed

- Removed the ordinary roaming-enemy population cap from authored mini-boss
  encounters.

## Fixed

- Fixed intermittent empty arenas whose enemies could appear only after the
  player interacted with the entrance gate.

<!-- developer-only -->
- Arena population now covers the complete entity replication radius rather
  than inheriting the narrower ordinary chunk-activation window.
<!-- /developer-only -->
