# Blender Sprite Studio Scripts (`tools/sprite-studio/blender`)

Python Blender scripts for cel-shaded orthographic rig generation and Action rendering:

- `studio_core.py`, `export_blend.py`, `export_player_layers.py`, `render_player_preview.py`: Shared lighting/camera core, creature batch renderer, Holdout layer exporter, and preview generator.
- `rigs/` & `actions/`: Modular rig builders (`build_*.py`) and procedural Action generators (`*_actions.py`).
