# `@dc2d/game-server`

Authoritative 20 Hz multiplayer server built on Node + `ws`:
- Evaluates infinite deterministic terrain via `@dc2d/engine`
- Drives authoritative 3-phase melee combat (`src/sim/combat/meleeTimeline.ts`, `statusEffects.ts` burn/venom poison DoT & water extinguish, heavy hold guard-break, timed parry -> `1.75×` riposte, spear shield-poke, pickaxe armor-crush + AoE slam, `0.18s` input buffer, windup dodge-cancel), gear RPG stats/perks (`src/sim/combat/gearEffects.ts`), proximity chat (`src/sim/chat/proximityChat.ts`), frontier discoveries, shrines, waystones & brazier vaults (`src/sim/frontier/`), dynamic spring-cloth webs & silk cocoons (`src/sim/webs/`), ecological wildlife AI with `DangerTier`/Elites & dynamic seeded loot (`src/sim/wildlife/`), synced Day/Night clock, and POI chests/loot
- Enforces server-side admin/debug authorization (`src/net/adminAuth.ts`, `src/sim/frontier/adminSlashCommands.ts`, `wsServer.ts`): open only on non-production builds without `DEBUG_COMMANDS=0`, or per-session in production after constant-time `ADMIN_TOKEN` authentication (`admin` / `debugSpawn` / `setDayPhase` / chat `/god`, `/give`, `/fillbag`, `/clearbag`, `/tp`, `/biome`, `/poi`)
- Broadcasts per-client AOI-culled snapshots (`src/net/snapshotFilter.ts`, dirty-checked `selfInventory`, `TCP_NODELAY`) over WebSocket, expires stale ground loot (`MAX_GROUND_LOOT_AGE_SEC`), flushes persistence asynchronously (`src/sim/survival/persistenceStore.ts`) plus synchronously on `SIGINT`/`SIGTERM` (`src/main.ts`), and bundles to `dist/main.cjs`
- Production containerization targets Fly.io `dfw` (`../../fly.toml`, `./Dockerfile`, `WORLD_SAVE_PATH=/data/world-save.json` on persistent `world_data` volume), activated in `.github/workflows/deploy-production.yml` via `FLY_API_TOKEN` and defaulting to `wss://ws.dungeoncrawl2d.austinwasinger.com/ws` (overridable via `VITE_GAME_WS_URL`; see [`docs/FLY-DEPLOYMENT.md`](../../docs/FLY-DEPLOYMENT.md) for full CLI, DNS, and token instructions)
