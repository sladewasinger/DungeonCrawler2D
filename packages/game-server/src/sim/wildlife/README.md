# Overworld Wildlife & Ecological POIs (`packages/game-server/src/sim/wildlife`)

Authoritative simulation of living forest wildlife, cognitive AI states, and deterministic POI landmarks:
- **`creatureSpecs.ts`**: Archetype combat/sensory/territorial definitions (`wolf`, `bear`, `spider`, `boar`, `slime`, `goblin`, `orc`, `skeleton`, `golem`) and `WildlifeEntity` state contract.
- **`scentTrail.ts`**: Timed scent-crumb buffer dropped by active or bleeding players outside Sanctuary.
- **`creatureBehaviors.ts` & `wolfPackAi.ts`**: Specialized steering, ally separation (`computeSeparation`), slime cohesion (`computeSlimeCohesion`), combat stand-off spacing, calm idle-pause patrol rhythms (`golem` holds stationary sentry idle), bear territorial bluffing vs feeding, boar wall-impact stagger stun, spider cover-ambush pounce, and cross-group wolf pack hive-mind rally + organic rear-flank dart bites.
- **`creatureNavigation.ts`**: Bounded A* pathfinding cache (`findTilePath`) with 1-tile platform jumping, tangential + radial `BlockingObstacle` avoidance (chests, campfires, dual-circle tents, props), `isClearSpot` spawn/patrol validation, velocity-aligned facing sync, and damped knockback velocity physics.
- **`creatureAi.ts`**: Shared 3-stage perception pipeline (`investigate` `?` -> timed `spottedPop` `!` -> distinct melee windup/charge), stealth visibility & noise radius scaling, outrun disengage for roaming enemies vs territorial chest-guard leashing for `orc` & `golem`, unreachable-ledge `2.5s` disengage, and Sanctuary safety.
- **`worldEcology.ts`**: Validated POI guard & wildlife spawning, `emitNoise` for pebbles/combat/sprinting, `2.25×` silent stealth backstabs, `debugSpawnNearPlayer`, chest interactions & magnetic loot/recoverable arrow collection, and swept-segment arrow simulation (`projectileSim.ts`).
