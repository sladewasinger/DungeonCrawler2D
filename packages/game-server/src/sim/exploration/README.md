# Exploration, Shrines & POIs (`packages/game-server/src/sim/exploration`)

Server-side progression for biome discovery, shrines, waystones, and brazier puzzles:

- `poiInteractions.ts`: Interactive handlers for Swiftness/Vigor/Shadow Shrines, Ancient Waystones, Lore Signs, Gravestones, Brazier Vaults, Runic Forges, and sanctuary protection helpers.
- `discoveryTracker.ts`: Per-player discovered biome/POI sets, XP/milestone notifications, and Waystone reveal beacons.
