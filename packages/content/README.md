# `@dc2d/content`

Pure game content definitions and visual palettes shared by server and client:
- Item definitions (`src/items/catalog.ts`) with `STARTER_LOADOUT` (`wooden-spear` only + `STARTER_ARMOR`), explicit `maxStack`, `twoHanded` (`bow`, `iron-greatsword`), `weaponArchetype` metadata across all 8 weapon archetypes (`sword`, `flint-dagger`, `wooden-spear`, `axe`, `pickaxe`, `iron-greatsword`, `torch`, `bow`), and `resolveBlockMode` (`none` / `shield` / `twoHanded`)
- Crafting recipes (`src/recipes/recipes.ts`), biome palettes, atmospheric light colors, outline presets, and client quality presets
