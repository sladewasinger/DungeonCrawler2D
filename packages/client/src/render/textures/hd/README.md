# HD Procedural Textures (`packages/client/src/render/textures/hd`)

48 px/tile HD-pixel texture bakers consumed by `../propTextures.ts`:

- `hdFireTextures.ts`: Animated campfire and torch flame frames.
- `hdFoliageTextures.ts`: HD trees, canopies, bushes, tall grass, and wildflowers.
- `hdPropTextures.ts`: HD boulders, cut stumps, and POI structure fallback sprites.
