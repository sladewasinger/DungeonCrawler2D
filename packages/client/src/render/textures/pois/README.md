# POI & Safe Room Textures (`packages/client/src/render/textures/pois`)

Procedural 48 px/tile HD-pixel textures for Overworld biome POIs and Sanctuary Safe-Room Hub fixtures:

- `biomePoiTextures.ts`: Shrines, Ancient Waystones, graves, broken carts, ruins, obelisks, braziers, hermit huts, and fairy rings.
- `safeRoomTextures.ts`: Floor-1 Sanctuary Hub & outer Safe-Room fixtures (`stash-chest`, `bounty-board`, `npc-guide`, `npc-merchant`, `npc-blacksmith`).
