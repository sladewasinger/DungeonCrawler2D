# Fallback Character Layers (`packages/client/src/render/character/layers`)

32×32 procedural fallback pixel layers for headless unit tests and non-3D fallbacks:

- `characterArmorLayers.ts`: 4-directional armor layer overlays.
- `characterBodyLayers.ts`: Base body, limbs, expressive eyes, and under-tunic layers.
- `characterHairLayers.ts`: 4-directional hair style painters.
