# Modular Layered Character Renderer (`render/character/`)

Renders 8-directional (`south`, `se`, `side` mirrored East/West, `ne`, `north`) hero sprites with runtime Sentinel palette recoloring, data-driven modular gear, baked 3D arms, and crisp solid Borderlands outlines (`32×32` procedural fallback preserved for headless unit tests):

- **3D Holdout Layer Pipeline (`playerAssets.ts`, `playerCompositor.ts`, `playerRecolor.ts`, `characterTypes.ts`, `characterSprites.ts`)**: `playerAssets.ts` loads `player-rig.json` (`cache: "no-cache"`) with `?v=<bakeVersion>` cache-busting, preloads all `meta.layers` + `bowOverlay` upfront with progress callbacks during the loading screen, resolves the portrait source cell (`resolvePortraitCell`, choosing the `idle` South-East `se` cell when present and falling back to `portraitRow`/`portraitCol`), and pre-slices `192×192` portrait cells (`getPlayerPortraitLayer`) while keeping all core layers pinned in the layer cache. `playerCompositor.ts` orders layers declaratively via `ItemDef.visualLayer` (`resolveLayerStack`), supporting both unified sculpted body/tunic sheets and backwards-compatible empty arm/sleeve overlays while exposing full-sheet baking (`build3dCharacterSpriteSet`) and fast portrait-only baking (`build3dCharacterPortraitUrl` + `computePortraitCropRect`). `playerRecolor.ts` remaps Sentinel skin/iris/hair bands (including two-tone hair gradients) in-place with `Uint32Array` transparent-pixel skipping and flat typed-array `FlatDiskOffsets` Borderlands `sel-out` outlines.
- **12 Clips (`61` rows)**: `idle` (`6 fps`), `walk` (`7 fps`), `run` (`11 fps`), `jump`, `fall`, `dodge` (6 frames), `downed`, `swim` (4 frames @ `6 fps`), `bow` (3 frames mapping ready -> half-draw -> full-draw), `crouch_idle` (4 frames), `crouch_walk` (6 frames), and `attack` (3 frames: horizontal windup / forward strike lunge / overhead slam), plus dedicated `portrait` crop row (`row 60`) and `water/waterSubmergeRig.ts`.
- **3D & Fallback Held Gear (`heldWeapons.ts`, `heldPlacement.ts`, `armRig.ts`, `playerAssets.ts`, `playerSprite.ts`, `playerPoseHelpers.ts`)**: Renders true 3D 8-direction held bow overlays (`weapon-bow.webp`, `getBowOverlayTexture`, depth-sorted across front/back slots with `syncBowAimGuide` dashed aim indicator) while actively aiming/drawing (`clip === "bow"`), and attaches `gear-bow` upright to the active hand socket when idle or moving un-aimed alongside `48 px/m` lossless WebP 3D gear sprites (`gear-sword`, `gear-flint-dagger`, `gear-wooden-spear`, `gear-iron-greatsword`, `gear-axe`, `gear-pickaxe`, `gear-bow` / `gear-bow-drawn`, `gear-shield`, `gear-torch-0..3`, `gear-lantern-0..1`) via `getLoadedSpriteAsset()` with `WeaponGripSockets`, two-handed greatsword/bow offhand slotting, and hip/hand Lantern slotting.
- **Caches**: `characterSprites.ts` maintains a bounded 64-entry LRU cache (`getCharacterSpriteSet`) for full directional sprite sets plus a 256-entry LRU portrait data-URL cache (`getCharacterPortraitUrl`) so UI pickers switch options without rebuilding full spritesheets.
