# Modular Layered Character Renderer (`render/character/`)

Renders 8-directional (`south`, `se`, `side` mirrored East/West, `ne`, `north`) hero sprites with runtime Sentinel palette recoloring and modular gear, retaining a `32×32` procedural fallback for headless unit tests:

- **3D Holdout Layer Pipeline (`playerAssets.ts`, `playerCompositor.ts`, `characterTypes.ts`, `characterSprites.ts`)**: `preloadPlayerAssets()` (called alongside `preloadSpriteManifest()`) loads 12 pre-baked `144×144` (`48 px/m`, `scale = 0.3333`) layer sheets plus `player-rig.json` projected shoulder sockets from `public/assets/player/`. `build3dCharacterSpriteSet()` stacks base body (`male` or `female` bare skin + cloth underwear), optional armor slots (`armor-feet-leather-boots`, `armor-legs-leather-leggings-*`, `armor-chest-leather-tunic-*`, `armor-head-leather-hood`), and exposed hair (`hair-*`), remaps Sentinel chroma bands (`SKIN_PALETTES`, `EYE_PALETTES`, `HAIR_PALETTES`), runs unified 2px rounded `sel-out` (`dx² + dy² <= 4`), slices 7 clips (`idle`, `walk` @ `7 fps`, `run` @ `11 fps` on Shift sprint, `jump`, `fall`, 6-frame `dodge` dive roll, `downed`), builds two-pass seamless capsule arm & outline textures (`ArmSegmentTextures`), and crops the full-arm `previewUrl` portrait for Hero Modal & Title Screen.
- **Ground-Anchored Shadow & Elevation (`playerSprite.ts`)**: Draws the dynamic contact shadow as a separate ground-anchored `Graphics` ellipse beneath `actorGroup` so jumping lifts the hero cleanly above a shrinking ground shadow, while `computeActorCombatFx(..., is3d: true)` omits legacy tilt/ghosting when 3D `dodge` and `downed` clips play.
- **3D & Fallback Held Gear (`heldWeapons.ts`, `heldPlacement.ts`, `armRig.ts`)**: Serves `48 px/m` 3D gear PNGs (`gear-sword`, `gear-axe`, `gear-pickaxe`, `gear-bow` / `gear-bow-drawn` when `bowCharge > 0.15`, `gear-shield`, `gear-torch-0..3`, `gear-lantern-0..1`) via `getLoadedSpriteAsset()` with proportional `WeaponGripSockets`, falling back to `bake()` canvases when unpreloaded. Keeps main weapons in the dominant right hand and the brass **Lantern** in the left hand (`handLantern` / `hipLantern` / `none`).
- **Cache**: `characterSprites.ts` maintains a bounded 64-entry LRU cache across all 5 directional clip sets + `armSegments`, destroying evicted Pixi textures cleanly.
