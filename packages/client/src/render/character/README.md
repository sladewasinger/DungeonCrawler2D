# Modular Layered Character Renderer (`render/character/`)

Renders 8-directional (`south`, `se`, `side` mirrored East/West, `ne`, `north`) hero sprites with runtime Sentinel palette recoloring, data-driven modular gear, baked 3D arms, and crisp solid Borderlands outlines (`32×32` procedural fallback preserved for headless unit tests):

- **3D Holdout Layer Pipeline (`playerAssets.ts`, `playerCompositor.ts`, `playerRecolor.ts`, `characterTypes.ts`, `characterSprites.ts`)**: `playerAssets.ts` loads `player-rig.json` (`cache: "no-cache"`) with `?v=<bakeVersion>` cache-busting, preloads core base sheets, and lazy-loads optional hair/armor `192×192` (`80 px/m`, `scale = 0.20`) layer sheets into a bounded 64-entry LRU cache (`ensurePlayerLayersLoaded`), bumping `getCharacterCacheRevision()` on completion. `playerCompositor.ts` orders layers declaratively via `ItemDef.visualLayer` (`resolveLayerStack`), building one unified full-arm/sleeve sheet per hero appearance across all poses (including `bow`). `playerRecolor.ts` remaps Sentinel skin/iris/hair bands including per-cell two-tone vertical hair gradients (`HAIR_PALETTES`) and applies uniform opaque solid Borderlands `sel-out` configured by `@dc2d/content` (`ACTIVE_OUTLINE_STYLE`).
- **12 Clips (`61` rows)**: `idle` (`6 fps`), `walk` (`7 fps`), `run` (`11 fps`), `jump`, `fall`, `dodge` (6 frames), `downed`, `swim` (4 frames @ `6 fps`), `bow` (3 frames mapping ready -> half-draw -> full-draw), `crouch_idle` (4 frames), `crouch_walk` (6 frames), and `attack` (3 frames: horizontal windup / forward strike lunge / overhead slam), plus `portrait` crop (`row 60`) and `water/waterSubmergeRig.ts`.
- **3D & Fallback Held Gear (`heldWeapons.ts`, `heldPlacement.ts`, `armRig.ts`, `playerAssets.ts`, `playerSprite.ts`, `playerPoseHelpers.ts`)**: Renders true 3D 8-direction held bow overlays (`weapon-bow.png`, `getBowOverlayTexture`, depth-sorted across front/back slots with `syncBowAimGuide` dashed aim indicator) while actively aiming/drawing (`clip === "bow"`), and attaches `gear-bow` upright to the active hand socket when idle or moving un-aimed alongside `48 px/m` 3D gear PNGs (`gear-sword`, `gear-flint-dagger`, `gear-wooden-spear`, `gear-iron-greatsword`, `gear-axe`, `gear-pickaxe`, `gear-bow` / `gear-bow-drawn`, `gear-shield`, `gear-torch-0..3`, `gear-lantern-0..1`) via `getLoadedSpriteAsset()` with `WeaponGripSockets`, two-handed greatsword/bow offhand slotting, and hip/hand Lantern slotting.
- **Cache**: `characterSprites.ts` maintains a bounded 64-entry LRU cache across directional clips, destroying evicted Pixi textures cleanly while sparing `Texture.EMPTY`.
