# Modular Layered Character Renderer (`render/character/`)

Renders 8-directional (`south`, `se`, `side` mirrored East/West, `ne`, `north`) hero sprites with runtime Sentinel palette recoloring, data-driven modular gear, baked 3D arms, and crisp solid Borderlands outlines (`32×32` procedural fallback preserved for headless unit tests):

- **3D Holdout Layer Pipeline (`playerAssets.ts`, `playerCompositor.ts`, `playerRecolor.ts`, `characterTypes.ts`, `characterSprites.ts`)**: `playerAssets.ts` loads `player-rig.json` (`cache: "no-cache"`) with `?v=<bakeVersion>` cache-busting, preloads core base sheets, and lazy-loads optional hair/armor `192×192` (`80 px/m`, `scale = 0.20`) layer sheets into a bounded 64-entry LRU cache (`ensurePlayerLayersLoaded`), bumping `getCharacterCacheRevision()` on completion. `playerCompositor.ts` orders layers declaratively via `ItemDef.visualLayer` (`resolveLayerStack`), building both the default **baked-arm sheet** (`body-*-arms` + `armor-chest-sleeves-*`) and a bow-only **armless sheet** (`CharacterSpriteSet.armless`). `playerRecolor.ts` remaps Sentinel skin/iris/hair bands including per-cell two-tone vertical hair gradients (`HAIR_PALETTES`) and applies uniform opaque solid Borderlands `sel-out` configured by `@dc2d/content` (`ACTIVE_OUTLINE_STYLE`).
- **8 Clips (`41` rows)**: `idle` (`6 fps`), `walk` (`7 fps`), `run` (`11 fps`), `jump`, `fall`, `dodge` (6 frames), `downed`, and `swim` (4 frames @ `6 fps`) plus full-arm `portrait` crop.
- **3D & Fallback Held Gear (`heldWeapons.ts`, `heldPlacement.ts`, `armRig.ts`)**: Serves `48 px/m` 3D gear PNGs (`gear-sword`, `gear-axe`, `gear-pickaxe`, `gear-bow` / `gear-bow-drawn`, `gear-shield`, `gear-torch-0..3`, `gear-lantern-0..1`) via `getLoadedSpriteAsset()` with `WeaponGripSockets` and hip/hand Lantern slotting.
- **Cache**: `characterSprites.ts` maintains a bounded 64-entry LRU cache across directional + `armless` clips & `armSegments`, destroying evicted Pixi textures cleanly.
