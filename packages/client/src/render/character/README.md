# Modular Layered Character Renderer (`render/character/`)

Renders 8-directional (`south`, `se`, `side` mirrored East/West, `ne`, `north`) hero sprites with runtime Sentinel palette recoloring, data-driven modular gear, baked 3D arms, and crisp solid Borderlands outlines (`32×32` procedural fallback preserved for headless unit tests):

- **3D Holdout Layer Pipeline (`playerAssets.ts`, `atlas/playerAtlasPacker.ts`, `playerCompositor.ts`, `playerRecolor.ts`, `characterTypes.ts`, `characterSprites.ts`)**: `playerAssets.ts` loads `player-rig.json` (`cache: "no-cache"`) with `?v=<bakeVersion>` cache-busting, preloads starter boot layers (`body-*`, `hair-*`, `armor-leather_*`) + `bowOverlay` upfront with progress callbacks during the loading screen while loading higher-tier armor layers lazily via `ensurePlayerLayersLoaded`, resolves the portrait source cell (`resolvePortraitCell`, choosing the `idle` South-East `se` cell when present and falling back to `portraitRow`/`portraitCol`), and pre-slices `192×192` portrait cells (`getPlayerPortraitLayer`) while keeping active layers cached. `atlas/playerAtlasPacker.ts` + `playerCompositor.ts` skip the `125` unused grid cells, trim transparent margins per clip using `player-rig.json` `clip.trim` rects (`buildTierAtlasPlan` shelf packing with `4px` gutters and `orig`/`trim` PixiJS v8 `Texture` frames so world/flip/bow alignment matches `192×192`), and split compositing into two mobile-safe `<= 2048×2048` GPU tiers: **Core** (`idle`, `walk`, `run`, `dodge`, `attack` — `125` frames, `~9.0 MiB` VRAM, baked immediately) and **Secondary** (`jump`, `fall`, `downed`, `swim`, `bow`, `crouch_idle`, `crouch_walk` — `115` frames, `~6.3 MiB` VRAM, lazily baked on first demand via `ensureSecondary` / `needsSecondaryAnimTier`, down from `~53.2 MiB`). `playerRecolor.ts` remaps Sentinel skin/iris/hair bands (including two-tone hair gradients) in-place per active slot with `Uint32Array` transparent-pixel skipping and flat typed-array `FlatDiskOffsets` Borderlands `sel-out` outlines.
- **12 Clips (`61` rows)**: `idle` (`6 fps`), `walk` (`7 fps`), `run` (`11 fps`), `jump`, `fall`, `dodge` (6 frames), `downed`, `swim` (4 frames @ `6 fps`), `bow` (3 frames mapping ready -> half-draw -> full-draw), `crouch_idle` (4 frames), `crouch_walk` (6 frames), and `attack` (3 frames: horizontal windup / forward strike lunge / overhead slam), plus dedicated `portrait` crop row (`row 60`) and `water/waterSubmergeRig.ts`.
- **3D & Fallback Held Gear (`heldWeapons.ts`, `atlas/tierHeldGear.ts`, `atlas/armorLayerRecolor.ts`, `heldPlacement.ts`, `armRig.ts`, `playerAssets.ts`, [`layers/`](./layers/README.md), `render/world/player/`)**: Renders luminance-recolored tiered armor sets (`recolorPrimary`/`recolorTrim`), true 3D 8-direction held bow overlays (`weapon-bow.webp`, `getBowOverlayTexture`, tinted per bow tier while aiming/drawing (`clip === "bow"`) across front/back slots with `syncBowAimGuide` dashed aim indicator), procedural outlined visuals for all 14 progressed weapons & 3 shield variants, and `48 px/m` lossless WebP 3D gear sprites via `getLoadedSpriteAsset()` with `WeaponGripSockets`, two-handed greatsword/bow offhand slotting, and hip/hand Lantern slotting.
- **Caches**: `characterSprites.ts` maintains a ref-counted, bounded 32-entry LRU cache (`acquireCharacterSpriteSet` / `releaseCharacterSpriteSet` / `getCharacterSpriteSet`, skipping in-use keys on eviction and cleanly disposing both Core and lazy Secondary GPU `TextureSource`s on eviction) plus a 256-entry LRU lazy portrait data-URL cache (`getCharacterPortraitUrl`, computing PNG data URLs only on demand) so UI pickers switch options without rebuilding spritesheets.
