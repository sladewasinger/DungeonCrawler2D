# Client Renderer (`packages/client/src/render`)

Isolated PixiJS v8 rendering subsystems:
- `textures/`: `32×32` toroidally wrapped homogeneous Cainos-style pixel terrain painters (`TERRAIN_TEX_PX = 32`, `terrainTextures.ts`, `terrainTileDetails.ts`, `terrainTileMotifs.ts`) packed into one extruded `136×306` GPU tileset atlas (`1px` gutter padding), foliage/campfire/torch sprites, `spriteManifest.ts` (static PNG & animated spritesheet preloader/clip slicer with `scaleMode: "nearest"` from `/assets/sprite-manifest.json`), and 1px outline helpers.
- `combat/`: `EntityRenderer` + `entityAnimator.ts` 4-dir / 8-dir (`skeleton`, `boar`) spritesheet animator (`idle`, `walk`, `run`, `attack`, `corpse`, ID phase + hysteresis + displacement gating + `jumpZ` vertical lift), world pickups, and gore/VFX (crimson local hurt popups).
- `shaders/`: WebGL2 GLSL GPU tilemap shader (`tilemapMesh.ts` + `glsl/tilemapGlsl.ts`) with per-cell toroidal sub-tile phase shifting sampling the shared tileset atlas from `4 KB`/chunk `RGBA8` lookup maps (`BufferImageSource`), plus water, foliage wind, lighting filters, directional cast shadows, and pooled GPU particles.
- `world/`: `32×32` GPU tilemap chunk setup (`tileBuilder.ts`), elevated `3/4` cliff plateau strips at `32px/tile` (`cliffStrips.ts`), `PlayerView` + `PlayerHpBar` overhead health bar & hurt/downed FX, chunk streaming, canopy alpha fade, and damped hit-shake camera orchestration.
