# Hybrid Web Audio Engine (`packages/client/src/audio/`)

Mobile-unlocked Web Audio mixer supporting zero-latency procedural synthesis out of the box:

- **`audioEngine.ts`**: Lazy `AudioContext` capture-phase gesture unlock (removing window unlock listeners once running), `DynamicsCompressorNode` master bus limiter, concurrent spatial voice capping (`MAX_CONCURRENT_VOICES = 24`), muted/discovery fast-paths, distance-attenuated and stereo-panned world event dispatch (`swing`, `hit` by `GoreSubstance` + delayed creature hurt/death layering, `telegraph`, `creatureVocal`, `block`, `parry`, `arrowFire`, `dodge`, `heal`, `respawn`), terrain footstep sync, and `Master` / `Music` / `SFX` buses.
- **`spatialMix.ts`**: Distance rolloff (`2.5` to `22` tiles), stereo pan clamping, distant-event culling, and Web Audio `GainNode` + `StereoPannerNode` bus helper.
- **`studioOverrides.ts`**: Reads saved Sound Studio presets from `localStorage` (`dc2d-sound-studio-presets-v1`) and listens for cross-tab `storage` updates so Sound Studio edits play live in Overworld and Sandbox.
- **`creatures/` ([`creatures/README.md`](./creatures/README.md))**: Organic vocal-tract growl synth (`vocalSynth.ts`) with `onended` AudioNode graph teardown and bespoke profiles for all 9 wildlife and POI guard archetypes (`bear`, `boar`, `wolf`, `spider`, `slime`, `goblin`, `orc`, `skeleton`, `golem`) across `alert`, `attack`, `charge`, `hurt`, and `death` cues, with Sound Studio preset overrides.
- **`ambienceBed.ts`**: Day/Night wind filter sweep, Dawn/Day birds ↔ Dusk/Night crickets, distance-attenuated spatial campfire crackle & river flow, and subtle reactive combat-tension pulse.
- **`proceduralSynth.ts`**: Shared multi-track procedural synthesis primitives used by both the game and Sound Studio — **White / Pink / Brown noise** generators (`fillNoiseSamples`, `getColoredNoiseBuffer`), Attack -> Hold -> Exponential Decay envelopes (`applyTrackEnvelope`), stereo panning (`connectWithPan`, `-1..+1`), exact track duration math (`exactTracksDurationSec`), offset playhead windowing (`computeTrackWindow`), `"vocal"` delegation (`scheduleVocalTrack`), and `playProceduralTracks`.
- **`synthSfx.ts`, `weapons/synthWeaponSfx.ts` & `weapons/synthCombatCues.ts`**: Pure Web Audio API combat/treasure/UI synthesis (`synthSwing` dispatched per weapon archetype — Sword 3-hit + lunge hiss, heavy Axe cleave, Pickaxe overhead stone/metal strike, Torch flame whoosh/crackle, plus Dagger/Spear/Greatsword — along with `synthImpact`, `synthCombatCue` including `guardBreak`, `riposte`, `heavyCharge`, `slamImpact`, `burnTick`, `burnExtinguish`, sharpened `backstab`, and `synthUi`).
- **`synthMovementSfx.ts`**: Terrain footsteps (`synthFootstep`), layered water splashes/plunge, and heavy dirt/clod landing crunch (`synthJumpOrLand`).
- **`audioTuning.ts`**: Single editable config object (`AUDIO_TUNING`) holding wind, campfire rumble/crackle/pop, river, biosphere, footstep (`masterGain`, `pitchScale`, `crunchMix`, `stepIntervalSec`), landing (`thudStartHz`/`EndHz`, `dirtStartHz`/`EndHz`, clod settle & `waterSplashMult`), and combat gains/frequencies.
- **`audioPrefs.ts`**: Persistent volume/mute settings saved in `localStorage`.
