# Client Biome & POI Discovery UI (`packages/client/src/ui/discovery`)

Biome entry banners, discovery count toasts, and interactive POI prompts:

- `discoveryOverlay.ts`: Animated biome/POI discovery banners (`X/20` landmarks), shrine/waystone buff feedback, and chime triggers.
- `poiPromptHelper.ts`: Distance-checked contextual `[E]` / tap prompt labels for nearby Waystones, Shrines, Braziers, Lore Signs, and Runic Forges.
- `discoveryStyles.ts`: Scoped banner and prompt styling.
