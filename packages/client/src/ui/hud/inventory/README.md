# HUD Inventory & Drag Modals (`packages/client/src/ui/hud/inventory`)

Interactive bag, chest, and pointer drag-and-drop inventory modules:

- `inventoryModal.ts`: 27-slot backpack, 5 armor/shield slots, stats summary, and Craft shortcut.
- `chestModal.ts`: Bidirectional 27-slot Chest <-> Backpack transfer modal.
- `slotDragManager.ts`: Pointer drag-and-drop, Shift/right-click transfers, hover previews, and drop-to-world.
