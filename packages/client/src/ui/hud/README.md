# Overworld HUD (`ui/hud/`)

Minimalist, mobile-first HUD adhering cleanly to the 36-slot RPG layout:

- **Top Toolbar & Settings (`atmosphereToolbar.ts`, `settings/`)**: Top-left displays a compact backpack icon button (with `?debug=1` gating server/FX/Atmosphere/Spawn tools). Top-right displays toggleable **`FpsCounter`** and **`PingCounter`** RTT telemetry (off by default on mobile), **`CompassBadge`** `(X, Y)` coordinate pill, and **Settings gear icon** opening the unified `SettingsMenu` (Hero/Respawn/Title Screen, Video/Quality/Gore/Relative Camera Zoom (`1.0×` = `4×` pixel zoom)/FPS/Ping/Hitbox Debug, Audio sliders, Mobile Auto-Aim toggle, and Crouch Key `Toggle (C)` / `Hold (C)` selector).
- **Bottom Hotbar (`bottomHotbar.ts`)**: Slots `0..8` plus the glowing/dimmed built-in **Lantern** toggle (`F`), compacted flush to bottom on mobile (`z-index: 40`).
- **Vitals (`vitalsBar.ts`)**: Centered HP bar + timed `FED Ns` / `REST Ns` survival buffs + `SWIFT`/`VIGOR`/`SHADOW` elixir & shrine buff pill + `POISONED Ns` (`POISONED` when cocoon-locked) / `STUCK` / `COCOONED` / `BURNING Ns` / `GOD` status pills + always-on constant-width Skyrim-style symbol-only Stealth Eye SVG (continuous eyelid openness with left Cover leaf and right Flame pips, zero text/percentage labels) + `Sanctuary` indicator above hotbar, paired with a left-edge **vertical Stamina bar** shifting blue → yellow → red as it drains.
- **Inventory Modal (`inventoryModal.ts`)**: Minimalist `[Tab]` / Backpack modal containing `27`-slot Backpack (`9..35`), `5` Armor/Shield slots, live Stats, and **`Craft`** (Crafting is accessible via Inventory only).
- **Bidirectional Chest Modal (`chestModal.ts`)**: Opened via `[E]`, tap-on-chest in range, or `[E] Open <POI Name>`; Minecraft-style `3×9` Chest beside `3×9` Backpack (`9..35`) + live Bottom Hotbar below with POI-specific headers and `"Inventory Full"` feedback.
- **Item Card Inspection (`itemCard/`, `slotDragManager.ts`)**: Desktop hover displays a non-blocking Item Card preview (`pointer-events: none`), tapping hotbar slots during gameplay selects without popping up the card, and tapping any filled slot while Inventory/Chest is open pins the interactive Item Card (64px icon, rarity glow, prefix + lore, green/red stat diffs vs equipped gear, perks, and contextual `Take`/`Store`/`Equip`/`Unequip`/`Use`/`Drop` actions) while keeping pointer drag-and-drop, right-click, and `Shift`-click quick transfer intact.
- **Forgiving Drag & Drop (`slotDragManager.ts`, `drag/slotDropResolver.ts`)**: Pure drag-and-drop & `Shift`-click quick transfer with nearest-slot gap snapping, drag-outside-HUD world item dropping (guarding modal/hotbar transitions), and `Q` / `Delete` / `Backspace` drop shortcut.
