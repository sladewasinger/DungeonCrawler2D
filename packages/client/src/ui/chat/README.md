# Client Proximity Chat (`packages/client/src/ui/chat`)

In-world proximity chat overlay and floating overhead speech bubbles:

- `chatOverlay.ts`: Collapsible `[Enter]` chat input bar, `[Shout]` mode toggle (`16`-tile normal radius vs `34`-tile shout radius), auto-expiring chat feed, and mobile toggle button.
- `chatStyles.ts`: Responsive chat feed, shout highlight, and input positioning styles above the bottom hotbar.
